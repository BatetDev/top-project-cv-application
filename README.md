## 📖 About

A CV builder application where users can enter their personal details, educational background, and practical experience, while seeing a live preview of the resulting CV.

The application emphasizes core React fundamentals:

- Component composition
- State management with `useState`
- One-way data flow
- Passing props and callback functions
- Controlled form inputs
- Rendering lists with keys
- Conditional rendering
- Lifting state up to a parent component

Built as part of The Odin Project’s React curriculum.

## 🌫️ Key Features

✅ Add, edit, and delete general information  
✅ Add, edit, and delete education entries  
✅ Add, edit, and delete experience entries  
✅ Live CV preview that updates as you type and save changes  
✅ Sample CV data loaded by default for easier testing  
✅ Clear CV button to reset all sections at once  
✅ Print / Save as PDF support with a print-friendly layout  
✅ Formatted date ranges, with fallback for current positions  
✅ Mobile-first responsive layout  
✅ Dark editor UI with a clean white CV preview

## 🧪 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/BatetDev/top-project-cv-application.git

# Navigate to project directory
cd top-project-cv-application

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
